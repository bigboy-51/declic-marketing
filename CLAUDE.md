# Declic Marketing - Karpathy-Style Operating Principles

This document defines how Claude operates within the Declic Marketing project. These principles are inspired by Andrej Karpathy's pragmatic approach to AI-assisted development.

## The Five Pillars

### 1. **Think Before Coding**
- Analyze the problem deeply before proposing solutions
- Understand requirements, constraints, and trade-offs
- Avoid the trap of immediate action without reasoning
- Question assumptions: "Is this what we really need?"

**Test:** Would a senior marketer review this analysis and nod in agreement?

### 2. **Simplicity First**
- Reject over-engineering and feature creep
- The simplest solution that achieves the goal wins
- Every complexity must earn its place
- "Clear is better than clever"

**Test:** Can a team member understand this without extensive documentation?

**Problem → Solution Table:**
| Temptation | Reality |
|-----------|---------|
| Complex multi-step funnel | Start with one clear conversion path |
| Fancy brand system | 5-color palette, 2 fonts, done |
| 50-slide pitch deck | 10 slides, one clear message |

### 3. **Surgical Changes**
- Each modification targets ONE goal precisely
- No "while we're here, let's improve..." side tasks
- No hidden refactoring masked as a fix
- Changes are minimal and intentional

**Test:** Can I explain this change in one sentence?

### 4. **Goal-Driven Execution**
- Every task transforms into verifiable success criteria
- No vague goals: "improve marketing" → "10% more email signups by June"
- Criteria are measurable before work begins
- "Done" means criteria met, nothing more

**Success Criteria Template:**
```
Goal: [Specific outcome]
Metric: [How we measure success]
Target: [Specific number/result]
Timeline: [When we validate]
```

### 5. **Verification/Challenge**
- Challenge every proposal before responding
- Question: "Is this actually the best approach?"
- Verify: "Does this match our constraints?"
- Test assumptions: "What if we're wrong about X?"
- Present alternatives when appropriate

**Test:** Did I question my own thinking before proposing this?

## Skills in This Project

Each skill follows these principles:

- **Copywriting** — Sales copy, emails, ads for Declic products
- **Branding** — Brand identity, tone, visual guidelines
- **Blogging** — Long-form content, SEO, audience engagement
- **YouTube Script** — Video scripts, editing strategy, hooks
- **Funnel** — Marketing funnel strategy, conversion paths
- **Design** — Visual direction, design systems, asset creation

---

## How to Use These Skills

1. Invoke a skill when its domain matches your task
2. Each skill includes structure, examples, and validation checklists
3. Follow the 5 pillars: think → simplify → surgical → measurable → verify

**Example workflow:**
```
Task: "Create a sales page for Declic Premium"
→ Think: Who's the buyer? What's the transformation?
→ Simplify: One main benefit, one CTA, three proof points
→ Surgical: Don't refactor the website while building this page
→ Measurable: "30% conversion rate or we iterate"
→ Verify: "Is this the clearest path to the sale?"
```

## Non-Goals

- No speculative features
- No "nice to have" additions
- No comments explaining the obvious
- No backwards-compatibility shims
- No over-architected solutions

## 2026 Best Practices (Evidence-Based)

These skills are informed by validated 2026 practices:

**Copywriting:** AIDA/PASTOR frameworks, first-person CTAs (+90% clicks), clarity = 23% conversion boost

**YouTube:** 65% retention with 3-second hooks, rewatch moments drive algorithm, 3-5 shorts/week optimal

**Branding:** One differentiator (not multiple), CX consistency = +20% revenue, clarity > volume

**Funnel:** Benchmarks (3.1% avg / 6.8% top quartile / 9.2% elite), quiz-based 40% conversion, AI-personalized +87%

**Blogging:** EEAT signals, topical authority (not single keywords), engagement time (not bounce rate)

**Design:** WCAG 2.2 compliance mandatory, accessibility-first, scalable component systems, dark mode required

## Cross-Skill Coherence

These skills work together:

1. **Branding** defines the voice → **Copywriting** executes it
2. **Funnel** strategy defines journey → **YouTube/Blogging** fill awareness
3. **Design** system supports all → Consistent visuals everywhere
4. **Funnel** metrics validate → All other skills contribute to conversion

Test coherence: Could a customer recognize your brand across copywriting + design + video + blog?
