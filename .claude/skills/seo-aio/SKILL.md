## The Three Pillars of AI-Era Visibility

### AIO (Artificial Intelligence Optimization)
**Goal:** Be understood, cited, recommended by all AI systems

**What AI needs:**
- Clear structure (headers, lists, summaries)
- Consistent terminology (use same words = same concept)
- Rich metadata (schema markup, descriptions)
- Authority signals (who wrote this? what's the source?)

**Tactical:**
- H1 = clear topic statement
- H2/H3 = subtopics (AI extracts these)
- Metadata: title, description, author, date
- Internal links: establish topical authority
- Schema markup: mark data, articles, reviews

### AEO (Answer Engine Optimization)
**Goal:** Be extracted as the direct answer to questions

**What Answer Engines need:**
- Direct answer at top (in first 100 words)
- Clear definitions (define terms before using)
- Structured data (lists, tables, bullet points)
- High confidence (cite sources, show data)

**Tactical:**
```
Question: "How much should I invest monthly?"
Answer Engine expects:
- Direct answer in first sentence
- Supporting data (tables, numbers)
- Source citations
- Confidence score based on authority

Good: "You should invest $500-1000/month. Research shows..."
Bad: "There are many factors to consider in investing."
```

### GEO (Generative Engine Optimization)
**Goal:** Be referenced in AI-generated summaries/responses

**What Generative Systems need:**
- Unique insights (not rehashed content)
- Citation-friendly format (easy to quote)
- High-quality data (research, case studies)
- Credibility (trust signals, sourcing)

**Tactical:**
- Unique research/data (AI cites novel insights)
- Pull quotes ready (format for easy extraction)
- Clear attribution (where data comes from)
- Credentials and authority (why should AI trust this?)

## AIO/AEO/GEO Across Content Types

### Blog Posts (AIO/AEO/GEO Priority)
```
AEO (High): Answer the question in first paragraph
GEO (High): Include unique research or data
AIO (Medium): Clear structure with headers

Example article on "Portfolio rebalancing":

[AEO] First 100 words:
"Rebalancing = selling winners, buying losers quarterly 
to maintain your target allocation. You should rebalance 
when any asset drifts > 5% from target. 
Here's exactly how..."

[GEO] Unique data:
"We analyzed 50K portfolios and found rebalancing 
improved returns by 12% vs. buy-and-hold."

[AIO] Structure:
H2: What is rebalancing
H2: Why rebalance
H2: How often to rebalance
```

### YouTube Videos (AIO/AEO/GEO Priority)
```
AEO (Highest): First 30 seconds answer the question
AIO (High): Consistent terminology, clear structure
GEO (High): High-quality transcript, citable moments

See YouTube Script skill for full implementation.
```

### Product/Landing Pages (AIO Priority)
```
AIO (Highest): Help AI understand what you offer
AEO (Medium): Answer common questions
GEO (Medium): Trust signals, credentials

Optimize for:
- Schema markup (product, organization)
- FAQ structure
- Clear value proposition
```

## Technical AIO Implementation

### Schema Markup (Essential for AI)

**Article schema:**
```json
{
  "@context": "schema.org",
  "type": "Article",
  "headline": "How to Make 50K Passive Income",
  "author": {"name": "Jane Investor", "type": "Person"},
  "datePublished": "2026-01-15",
  "description": "Data-driven portfolio strategy",
  "articleBody": "..."
}
```

**Organization schema:**
```json
{
  "@context": "schema.org",
  "type": "Organization",
  "name": "Declic Financier",
  "logo": "https://...",
  "sameAs": ["https://twitter.com/...", "https://linkedin.com/..."]
}
```

AI uses schema to understand what content is about and who created it.

### Core Web Vitals (Performance for AI)
- **LCP (Largest Contentful Paint):** < 2.5 seconds
- **INP (Interaction to Next Paint):** < 200ms
- **CLS (Cumulative Layout Shift):** < 0.1

Why AI cares: Slow pages = worse user experience = lower quality signal

## Keyword Strategy in AI Era

**Old approach:** "Rank #1 for 'portfolio management'"

**New approach:** "Own answer to questions about portfolio management"

**Shift:**
- Google: keyword volume + competition
- AI answers: question coverage + unique insights

**Example:**
```
Old: Optimize for "passive income strategies"
New: Answer:
  - "How much passive income can I make?"
  - "What's the best passive income strategy?"
  - "How long until I earn 50K passive income?"
  - "Can I make passive income with $5K?"
```

## Checklist: Is Your Content AIO/AEO/GEO Ready?

### AEO (Answer Engine Optimization)
- [ ] Question answered in first 100 words
- [ ] Key answer in first sentence
- [ ] Define all technical terms
- [ ] Cite sources for claims
- [ ] Format: lists, tables, bullets (extractable)
- [ ] Different questions answered throughout

### AIO (AI Understanding)
- [ ] Clear heading hierarchy (H1 → H2 → H3)
- [ ] Consistent terminology throughout
- [ ] Schema markup present (article, organization)
- [ ] Author credentials visible
- [ ] Internal links (topical authority)
- [ ] Content type marked (guide, article, review)

### GEO (Generative Optimization)
- [ ] Unique data or research included
- [ ] Pull quotes formatted clearly
- [ ] Specific numbers/data (not vague)
- [ ] Original insights (not regurgitated)
- [ ] Sources cited (builds trust)
- [ ] High-quality presentation
