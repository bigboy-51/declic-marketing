# Hooks Skill

## Purpose
Create magnetic openings across ANY format that stop scrolling, spark curiosity, and compel action. One universal framework + format-specific applications.

**2026 Reality:**
- 65% of viewers abandon videos in first 3 seconds (without hook)
- Headlines with curiosity gap = +40% click-through rate
- Email subject lines with pattern interrupt = +35% open rate
- Blog intros with value promise = +50% time-on-page
- 92% of attention is in the first line, not the full piece

---

## The Universal Hook Formula

```
[PSYCHOLOGICAL TRIGGER] + [SPECIFIC PROMISE] + [WHY NOW]

❌ Generic (No hook)
"Here's how to make money"

✅ Hook (Curiosity Gap)
"Most people miss the #1 way to make money. 
Here's why the smart investors are doing it now."

Breakdown:
[TRIGGER: "Most people miss"]
[PROMISE: "the #1 way to make money"]
[WHY NOW: "Smart investors are doing it now"]
```

## 5 Psychological Triggers (Choose 1 Per Hook)

### 1. Curiosity Gap (Highest Converting - 40%+ boost)

**Psychology:** Humans hate not knowing. We're drawn to close the gap.

**Formula:**
```
[Reveal problem/benefit WITHOUT solution] + [Promise to solve]
```

**Examples:**

Video:
```
"This portfolio made 67% more than S&P 500.
Here's the ONE thing most investors get wrong..."
```

Copy/Headlines:
```
"The #4 way to make $50K/year. (Most people skip it.)"
"Why 85% of investors leave $40K on the table"
"This one metric changed everything"
```

Email Subject:
```
"The $50K mistake I almost made (here's what saved me)"
"What the top 1% know about portfolios"
```

Blog Intro:
```
"I thought I was doing everything right with my portfolio.
Then I discovered one overlooked fact that changed everything.
Here it is..."
```

Lead Magnet:
```
"Take this 2-minute quiz to see how much money 
you're probably leaving on the table"
```

**Data:** Curiosity gap converts at 40-50% higher rate than alternatives.

---

### 2. Pattern Interrupt (Visual/Audio Surprise - 35%+ boost)

**Psychology:** Our brains ignore predictable patterns. Break the pattern = attention.

**Formula:**
```
[Unexpected statement/image/fact] + [Credibility] + [Benefit]
```

**Examples:**

Video:
```
"Before you invest another dollar, watch this."
"Financial advisors hate this one trick"
"Most people are doing it backwards"
```

Copy/Headlines:
```
"This strategy is so simple, you'll wonder why no one told you"
"The investing advice you've been getting is wrong"
"Stop doing what 99% of investors are doing"
```

Email Subject:
```
"I told my financial advisor what I was doing. 
His reaction was surprising."
"The truth about passive income (they don't want you to know)"
```

Blog Intro:
```
"Everything you learned about portfolio management is outdated.
Here's what works now..."
```

**Data:** Pattern interrupt = 35-40% engagement boost, especially in crowded feeds.

---

### 3. Social Proof / Status (Authority Signal - 30%+ boost)

**Psychology:** We trust what others like us are doing.

**Formula:**
```
[Who is doing this] + [Surprising result] + [Why they chose it]
```

**Examples:**

Video:
```
"Warren Buffett revealed why 90% of investors fail.
Here's what he actually recommended..."
```

Copy/Headlines:
```
"The strategy 10,000+ busy professionals are using"
"What millionaires know about passive income"
"How the top 1% structure their portfolios"
```

Email Subject:
```
"120 busy professionals just joined. Here's what they saw:"
"What Sarah discovered (she's an exec at Google)"
```

Blog Intro:
```
"After analyzing 50,000+ portfolios, we found one pattern.
The top performers all do this..."
```

Lead Magnet:
```
"Join 5,000+ investors who've used this assessment"
```

**Data:** Social proof = 30-35% conversion lift, especially B2B/professional audiences.

---

### 4. Scarcity / Urgency (Time/Limit Pressure - 25%+ boost)

**Psychology:** Fear of loss > gain motivation. Limited = valuable.

**Formula:**
```
[Specific scarcity] + [Deadline] + [Consequence]
```

**Examples:**

Video:
```
"Only 2% of people know this strategy.
If you're not in that 2%, here's why it matters..."
```

Copy/Headlines:
```
"Only 50 spots left for this quarter"
"This strategy worked until 2024. Here's what's next..."
"The window for this approach is closing"
```

Email Subject:
```
"Last chance: founder pricing expires in 24h"
"Only 3 seats left in this cohort"
```

Blog Intro:
```
"This tax strategy is changing in 2025.
Before new rules take effect, here's how to optimize now..."
```

**Data:** Scarcity = 25-30% conversion lift. Use ONLY if real (fake scarcity backfires).

---

### 5. Value Promise (Benefit-First - 30%+ boost)

**Psychology:** Immediately show "what's in it for me."

**Formula:**
```
[Specific benefit] + [Time/effort investment] + [Proof it works]
```

**Examples:**

Video:
```
"In the next 7 minutes, you'll learn the exact system 
that turned my $50K into $150K in returns..."
```

Copy/Headlines:
```
"See your potential returns in 60 seconds"
"The 3-minute portfolio audit (results in your inbox)"
"Discover exactly how much you're leaving on the table"
```

Email Subject:
```
"Here's your $47K opportunity (takes 5 min to see)"
"Your free portfolio assessment is ready"
```

Blog Intro:
```
"By the end of this article, you'll have a concrete action plan
to optimize your portfolio in the next 30 days..."
```

Lead Magnet:
```
"Instant: See your potential passive income (personalized)"
```

**Data:** Value promise = 30-35% conversion, especially for bottom-funnel content.

## Format-Specific Applications

### Video Hooks (YouTube, TikTok, Shorts)

**Position:** 0:00-0:03 (death zone)

**Rules:**
- Speak within 3 seconds
- No intro/logo/animation first
- Answer "why should I watch?" immediately
- Strong vocal pacing (varies tone, not monotone)

**Structure:**
```
[Hook - 0:00 to 0:02]
"This portfolio made 67% more than S&P 500"

[Promise - 0:02 to 0:03]
"Here's exactly how. (Takes 8 minutes to learn)"

[Credibility - 0:03 to 0:10]
"I analyzed 50K portfolios. Here's the pattern..."
```

**Best Hook Type for Video:** Curiosity Gap or Pattern Interrupt
- Curiosity Gap: 40-50% hook retention
- Pattern Interrupt: 35-40% hook retention
- Social Proof: 30-35% hook retention

---

### Copy / Ad Hooks (Headlines, CTAs, Ads)

**Position:** First line (they decide in 2 seconds)

**Rules:**
- Maximum 10 words (headlines)
- One clear benefit
- Optional: specific number or curiosity
- Action-oriented language

**Structure:**
```
[Benefit/Trigger - 1-5 words]
"This portfolio strategy"

[Specificity - 3-5 words]
"made 67% more returns"

[Optional curiosity/proof - 2-3 words]
"Here's why"

Full: "This portfolio strategy made 67% more. Here's why"
```

**Best Hook Type for Copy:** Curiosity Gap or Value Promise
- Curiosity Gap: 40-45% CTR boost
- Value Promise: 30-35% CTR boost
- Pattern Interrupt: 25-30% CTR boost

---

### Email Hooks (Subject Lines & Openers)

**Position:** Subject line (decide to open), First sentence (decide to read)

**Rules:**
- Subject line: 40-50 characters max
- Opener: 1-2 sentences max
- Must make person FEEL something (curiosity, surprise, FOMO)
- Personalization optional (name, company, etc.)

**Structure:**

Subject Line:
```
[Curiosity/Trigger] + [Benefit] + [Optional specificity]
"I told my financial advisor what I was doing. His reaction was surprising."
```

Email Opener:
```
[Hook restatement] + [Proof it's real] + [Next step]
"You might be leaving $40K+ on the table every year.
That's what we found analyzing 50K portfolios.
Here's your personal analysis:"
```

**Best Hook Type for Email:** Pattern Interrupt or Curiosity Gap
- Pattern Interrupt: 35-40% open rate boost
- Curiosity Gap: 40-45% open rate boost
- Scarcity: 25-30% open rate boost (time-limited content)

---

### Blog Hooks (Introductions, Pull Quotes, Headlines)

**Position:** First 2 lines (decide to scroll)

**Rules:**
- Write intro AFTER article (you'll know the key insight)
- Make first sentence compelling, not explanatory
- Use pattern interrupt or value promise
- Show reader "you're in the right place"

**Structure:**
```
Line 1: [Pattern interrupt or hook]
"Most financial advisors are actually hurting your returns."

Line 2: [Specific problem acknowledged]
"If you've built a 'balanced' portfolio following their advice, 
you're probably leaving $50K+ on the table."

Line 3: [Proof incoming]
"After analyzing 50K portfolios, here's what the top performers do differently..."
```

**Best Hook Type for Blog:** Value Promise or Curiosity Gap
- Value Promise: 50%+ time-on-page boost
- Curiosity Gap: 40-45% time-on-page boost
- Pattern Interrupt: 35-40% time-on-page boost

---

### Lead Magnet Hooks (Quiz intros, Page headlines, CTAs)

**Position:** Headline + subheading (first 5 seconds)

**Rules:**
- Specific benefit (not generic "free guide")
- Clear time investment ("2 min quiz", "5 min assessment")
- Personalized outcome promise
- FOMO optional (social proof of others taking it)

**Structure:**
```
Headline: [Curiosity gap or benefit]
"Discover how much money you're leaving on the table"

Subheading: [Specificity + time]
"This 2-minute assessment shows your exact opportunity (personalized)"

Social proof: [Who's using it]
"5,000+ investors have already taken it"

CTA: [Action + outcome]
"Take the Quiz → See Your Potential"
```

**Best Hook Type for Lead Magnets:** Curiosity Gap (40.1% conversion) or Value Promise
- Curiosity Gap: 40-45% signup rate
- Value Promise: 35-40% signup rate
- Pattern Interrupt: 30-35% signup rate

## Hook Psychology: Why These Work

### Curiosity Gap
- **Brain mechanism:** Our brain is drawn to close information gaps
- **Trigger:** Hint at benefit WITHOUT immediately revealing it
- **Optimal gap size:** ~5 seconds to answer ("Before you watch, know this...")
- **Risk:** If answer is disappointing, trust drops

### Pattern Interrupt
- **Brain mechanism:** Our reticular activating system ignores patterns, notices deviations
- **Trigger:** Break expectation in obvious way (size, emotion, statement)
- **Optimal shock:** Surprising but believable
- **Risk:** Shock fatigue if overused (need variety)

### Social Proof
- **Brain mechanism:** Conformity bias (we follow what "people like us" do)
- **Trigger:** Specific people/numbers who've succeeded
- **Optimal specificity:** Name/title/result (not vague "thousands of people")
- **Risk:** Fake/exaggerated proof destroys trust faster than no proof

### Scarcity
- **Brain mechanism:** Loss aversion (fear of missing out > gain of having)
- **Trigger:** Real limit (time, spots, data)
- **Optimal deadline:** Specific date (not "soon")
- **Risk:** Fake scarcity creates refund/churn later

### Value Promise
- **Brain mechanism:** People want to know ROI immediately
- **Trigger:** Specific benefit + time investment
- **Optimal promise:** Achievable, specific, measurable
- **Risk:** Over-promise = disappointment = churn

## Common Hook Mistakes (Don't Do These)

### ❌ Mistake 1: Generic Hook
```
❌ "Learn how to invest"
✅ "This portfolio made 67% more. Here's exactly how."
```
**Why it fails:** No curiosity, no specificity, no benefit.

### ❌ Mistake 2: Hook Too Long
```
❌ "Before we get into portfolio strategies, let me explain 
   the history of investing and why most people fail..."
✅ "Most people's portfolios are leaving $50K on the table."
```
**Why it fails:** Attention span < 3 seconds. Too much context kills curiosity.

### ❌ Mistake 3: Weak Specificity
```
❌ "Learn some cool investment tips"
✅ "Here are the 3 moves that created 67% higher returns"
```
**Why it fails:** Vague = low trust. Specific numbers = high trust.

### ❌ Mistake 4: Hook Doesn't Match Format
```
❌ Video hook: "Let me tell you about the history of..." (for 3 sec)
✅ Video hook: "This changed everything." (fast, punchy)
```
**Why it fails:** Different formats need different hook pacing.

### ❌ Mistake 5: False Scarcity
```
❌ "Only 5 spots left!" (Actually 100 spots)
✅ "Founder pricing ends Friday" (Actually ends Friday)
```
**Why it fails:** Broken trust destroys lifetime value.

### ❌ Mistake 6: Hook Doesn't Deliver
```
❌ Hook: "This portfolio made 200% returns"
   Content: "Returns vary, average is 8%"
✅ Hook: "This portfolio made 67% more than S&P 500"
   Content: [Proof, data, case study]
```
**Why it fails:** Expectation gap = refund, churn, negative reviews.

## Hook Formula by Use Case

### New Audience (Cold Traffic)
Need stronger hook. Use:
1. Pattern Interrupt (stop scroll)
2. Social Proof (establish credibility)
3. High curiosity gap

```
"Most financial advisors are doing it wrong.
(Here's what the top 1% know)"
```

### Warm Audience (Email List)
Can be softer. Use:
1. Value Promise (they know you)
2. Curiosity Gap (gentle)
3. Specific benefit

```
"Your personal $50K opportunity is ready
(See exactly where in your portfolio)"
```

### Existing Customers (Upsell)
Can assume familiarity. Use:
1. New problem/solution pairing
2. Upgrade benefit
3. Social proof from others

```
"Advanced portfolio owners are doing this now.
Here's the strategy that increases returns another 15%"
```

## Quality Checklist

Before shipping any hook:

- [ ] **Specific**: Contains number, % amount, or clear benefit (not generic)
- [ ] **Time-bounded**: Reader knows how long it takes (3 min video, 2 min quiz)
- [ ] **Credible**: Makes promise you can actually deliver
- [ ] **Relevant**: Speaks to actual pain point / desire
- [ ] **Matches format**: 
  - Video: 3 seconds max, fast pacing
  - Email: 40 char max subject line
  - Copy: 1-2 sentences
  - Blog: First 2 lines compelling
  - Lead magnet: Clear benefit + time investment
- [ ] **One hook type**: Uses only 1 psychological trigger (not mixed)
- [ ] **Curious**: Makes reader want answer within 5 seconds
- [ ] **Deliverable**: Content can deliver what hook promises
- [ ] **Authentic**: Based on truth, not manipulation
